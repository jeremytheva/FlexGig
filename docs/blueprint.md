# **App Name**: FlexGig Marketplace

## Core Features:

- Dual Intake Gateway: Clients choose between Managed Service (premium) or Direct Service (low-fee).
- Intelligent Matching: Matches projects to freelancers based on skills, availability, and PM workload using a matching tool.
- Freelancer Scheduling: Freelancers set and lock in flexible availability via an enforced calendar.
- Project Manager Dashboard: PMs get a real-time view of freelancer capacity.
- Approval Gate: Funds are released only after the client approves final deliverables.
- Legal & Compliance Hub: Skill tests and digital contract signing, including a mandatory arbitration clause, for talent pool quality control and risk mitigation.
- Three-Way Chat Bridge: PMs are the sole communication link between clients and freelancers, and will be acting as a translation tool to filter irrelevant detail and maintain project quality.
- AI-Driven Scope Vetting: Gemini-powered assistant provides PMs with clarifying questions and a scope risk score for new projects using a risk assessment tool.
- Integrated Escalation/Upsell Prompt: "Upgrade to Managed Service" button triggers automated message to a PM, suggesting an upsell after two revisions.

## Style Guidelines:

- Primary color: Vibrant blue (#29ABE2) reflecting reliability and innovation.
- Background color: Light blue (#E5F6FD), a very desaturated variant of the primary, for a calm backdrop.
- Accent color: Purple (#9C27B0) to highlight key actions and elements, being an analogous yet contrasting hue.
- Headline font: 'Space Grotesk', a sans-serif for headlines with a computerized feel; body font: 'Inter' (sans-serif) for a clean and neutral readability.
- Clean, modern icons that represent tasks, skills, and platform features.
- Clean and structured layout that will easily differentiate between managed services and direct services. Card based layouts will promote ease of navigation.
- Subtle transitions and animations for feedback on user interactions.
